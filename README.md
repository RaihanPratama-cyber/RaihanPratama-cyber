## 🧪 What I'm learning in the lab

- **Workshop Keamanan Jaringan IoT (WKJ):** MAC flooding (`macof`, 54-byte frames), DHCP starvation (`yersinia`, 3,306,566 DISCOVER packets), password sniffing with Wireshark, ARP poisoning with Cain & Abel and `hping3`.
- **EC Council — Social Engineering & Phishing:** Social-Engineer Toolkit (Site Cloner, Custom Import), phishing detection with the Netcraft Extension, and AI-assisted phishing simulation in a controlled lab.
- **Machine Learning for IoT:** image classification (messy vs clean, cat vs dog with MobileNetV2), audio classification, and speech commands.
- **Big Data:** IoT air-quality monitoring in Pekanbaru — data cleaning, MongoDB, analysis, and dashboard visualisation.
- **Computer Networks & CI/CD:** Git & GitHub, Docker, Jenkins pipelines, and Flask apps.
